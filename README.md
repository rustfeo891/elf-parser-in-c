# elf-parser-in-c
a simple elf parser in c

# How to use
make <br>
or <br>
./elf_parser.sh "<b>if you are not using gcc you can change the compiler options in elf_parser.sh by modifying gcc to the compiler you are using like clang</b>"<br>

./elf_parser "your elf program name"
